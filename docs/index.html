Wrapper 0.3.0-2 interfaces

Wrapper 0.3.0-2 extends the Java interfaces while continuing to use OpenZL 0.3.0. Publication follows release validation. These methods are not available in 0.3.0-1.

  • compressInputs(TypedInput...) and decompressOutputs(...) support mixed serial, numeric, fixed-width and binary string streams. Array/buffer factories snapshot inputs and preserve buffer cursors.
  • CompressionOptions, DecompressionOptions and LzOptions expose checksums, codec fusion and advanced LZ settings.
  • OpenZLException carries native codes/context for typed operations; named compression/decompression warning getters return snapshots.
  • setTryGraphCacheBudget(bytes) opts into caching eligible codec outputs during graph trials. Zero disables it. The budget covers cached entry payloads, not all native memory.
  • DictionaryBundleProvider loads a dictionary bundle from a frame's ID before decoding. Callbacks run before native array pinning; independent compressor instances can share a thread-safe provider.
  • OpenZLProtobuf.trainCandidates preserves graphs and bundles. Use convertWithCandidate, convertWithDictionary or convertWithDictionaryProvider for dictionary-aware conversion.

The interface guide covers examples, persistence and cleanup. Existing graph-only training and conversion calls remain available.

What's new in 0.3.0-1

This release wraps OpenZL 0.3.0. Release numbers follow upstream-version-wrapper-revision: the first wrapper release for each upstream version ends in -1.

  • Numeric Compression Transformer builds a graph for each input at level 7 and above.
  • LZ profile and trainer use the upgraded native LZ engine. Big-endian integer profiles and SDDL2 are also available.
  • Training candidates preserve both the graph and dictionary bundle for saving and reuse.
  • Brute-force selection and binary graph persistence let you reuse a configured compressor.
  • Frame format 27 is the default; select 24 explicitly when writing for OpenZL 0.2.0 readers.

In a small Linux benchmark against the published 0.2.0-1 release, level-6 numeric compression improved by about 12–33%, while ZSTD byte-array speed stayed close to the earlier release. These synthetic results depend on the workload and machine. See the benchmark method and full results and upstream release notes.

Getting started

Add the portable Java artifact and the classifier that matches your platform. Replace the classifier with macos_arm64 or windows_amd64 when needed. 

<dependency>
  <groupId>io.github.hybledav</groupId>
  <artifactId>openzl-jni</artifactId>
  <version>VERSION</version>
</dependency>

<dependency>
  <groupId>io.github.hybledav</groupId>
  <artifactId>openzl-jni</artifactId>
  <version>VERSION</version>
  <classifier>linux_amd64</classifier>
</dependency>

Java 11 or newer is supported at runtime. Releases are built with JDK 21 and classes are compiled with --release 11. The 0.3.0-2 source is also tested with JDK 25. Java 25 applications on the class path should launch with --enable-native-access=ALL-UNNAMED. See the Java 25 guide. OpenZLNative.load() extracts the bundled libopenzl_jni library automatically.

Published coordinates: io.github.hybledav:openzl-jni on Maven Central. Replace VERSION with the release listed there.

Quick start: byte array round trip

import io.github.hybledav.OpenZLCompressor;
import io.github.hybledav.OpenZLCompressionInfo;

byte[] payload = "openzl-jni quick start".getBytes(StandardCharsets.UTF_8);

try (OpenZLCompressor compressor = new OpenZLCompressor()) {
    byte[] compressed = compressor.compress(payload);
    byte[] restored = compressor.decompress(compressed);

    OpenZLCompressionInfo info = compressor.inspect(compressed);
    System.out.printf("restored=%s, compressed=%d bytes%n",
            java.util.Arrays.equals(payload, restored),
            info.compressedSize());
}

By default OpenZLCompressor uses the ZSTD graph. The inspect call returns size information, detected graph, data flavour, element count, and format version.

Direct buffers and pooling

import io.github.hybledav.OpenZLBufferManager;
import io.github.hybledav.OpenZLCompressor;

byte[] payload = "direct buffers keep JNI zero-copy".getBytes(StandardCharsets.UTF_8);

try (OpenZLBufferManager buffers = OpenZLBufferManager.builder()
        .minimumCapacity(1 << 12)
        .alignment(256)
        .build();
     OpenZLCompressor compressor = new OpenZLCompressor()) {

    ByteBuffer src = buffers.acquire(payload.length);
    src.put(payload).flip();

    ByteBuffer compressed = compressor.compress(src, buffers);
    ByteBuffer restored = compressor.decompress(compressed, buffers);

    byte[] roundTrip = new byte[restored.remaining()];
    restored.get(roundTrip);
    System.out.println("round-trip ok? " + java.util.Arrays.equals(payload, roundTrip));

    buffers.release(src);
    buffers.release(compressed);
    buffers.release(restored);
}

Use compress(src, dst) when you manage the destination buffer yourself. The static helper OpenZLCompressor.maxCompressedSize(int) returns the upper bound used by acquireForCompression. Destination buffers must be writable; input and output regions must not overlap. Use a separate compressor instance for each concurrent operation.

Numeric helpers

import io.github.hybledav.OpenZLCompressor;
import io.github.hybledav.OpenZLCompressionInfo;
import io.github.hybledav.OpenZLGraph;

int[] readings = new int[1024];
for (int i = 0; i < readings.length; i++) {
    readings[i] = (i % 17) * 42;
}

try (OpenZLCompressor compressor = new OpenZLCompressor(OpenZLGraph.NUMERIC)) {
    byte[] compressed = compressor.compressInts(readings);
    int[] restored = compressor.decompressInts(compressed);

    OpenZLCompressionInfo info = compressor.inspect(compressed);
    System.out.println("graph=" + info.graph() + ", flavor=" + info.flavor());
}

Array helpers exist for long, float, and double. Empty arrays return byte[0]. These methods avoid extra array-to-byte conversions when the data is already typed.

Numeric Compression Transformer

NUMERIC uses the Transformer at compression level 7 and above. The default remains level 6. The Transformer chooses a graph for each numeric input without sample training; measure the speed/size tradeoff on your own data before increasing the level.

import io.github.hybledav.*;
import java.util.Arrays;

int[] readings = new int[4096];
for (int i = 0; i < readings.length; i++) readings[i] = i * 4 + i % 4;
try (OpenZLCompressor compressor = new OpenZLCompressor(OpenZLGraph.NUMERIC)) {
    compressor.setCompressionLevel(OpenZLCompressionLevel.LEVEL_7);
    byte[] frame = compressor.compressInts(readings);
    if (!Arrays.equals(readings, compressor.decompressInts(frame))) {
        throw new IllegalStateException("Numeric round trip failed");
    }
}

Use new OpenZLCompressor(OpenZLGraph.TRANSFORMER_NUMERIC) to select the Transformer directly. Typed int, long, float and double helpers work with it. These new frames need a compatible newer reader.

Structured data with SDDL

import io.github.hybledav.OpenZLCompressor;
import io.github.hybledav.OpenZLProfile;
import io.github.hybledav.OpenZLSddl;

String rowStreamSddl = String.join("\n",
        "field_width = 4;",
        "Field1 = Byte[field_width];",
        "Field2 = Byte[field_width];",
        "Row = {",
        "  Field1;",
        "  Field2;",
        "};",
        "row_width = sizeof Row;",
        "input_size = _rem;",
        "row_count = input_size / row_width;",
        "expect input_size % row_width == 0;",
        "RowArray = Row[row_count];",
        ": RowArray;");

byte[] compiled = OpenZLSddl.compile(rowStreamSddl, true, 0);
byte[] payload = "12345678".repeat(128).getBytes(StandardCharsets.US_ASCII);

try (OpenZLCompressor compressor = new OpenZLCompressor()) {
    compressor.configureProfile(OpenZLProfile.SERIAL, java.util.Map.of());
    byte[] serial = compressor.compress(payload);

    compressor.reset();
    compressor.configureSddl(compiled);
    byte[] structured = compressor.compress(payload);

    System.out.printf("serial=%d B, sddl=%d B%n", serial.length, structured.length);
}

reset() retains the current graph, level, target format and dictionary bundle. Use configureProfile or configureSddl to select another pipeline. OpenZLSddl.compile compiles SDDL v1. To load an SDDL2 file, use configureProfile(OpenZLProfile.SDDL2, Map.of("TBD", descriptionPath)).

Inspecting frame metadata

import io.github.hybledav.OpenZLCompressor;
import io.github.hybledav.OpenZLCompressionInfo;
import io.github.hybledav.OpenZLCompressionLevel;

byte[] payload = "inspect me for metadata".getBytes(StandardCharsets.UTF_8);

try (OpenZLCompressor compressor = new OpenZLCompressor()) {
    compressor.setCompressionLevel(OpenZLCompressionLevel.LEVEL_5);
    byte[] compressed = compressor.compress(payload);

    OpenZLCompressionInfo info = compressor.inspect(compressed);
    System.out.printf("original=%d, compressed=%d, flavor=%s%n",
            info.originalSize(),
            info.compressedSize(),
            info.flavor());
}

OpenZLCompressionInfo also exposes compressionRatio(), the inferred OpenZLGraph, and optional element counts for structured frames. Use serialize() or serializeToJson() for inspection; use serializeCompressor() for binary graph persistence, saving any dictionary bundle separately.

Using the LZ profile

Set the compression level before configuring a profile so its graph generator can use that level. Levels 1–7 select the LZ engine's supported compression tradeoffs.

import io.github.hybledav.*;
import java.nio.charset.StandardCharsets;
import java.util.Arrays;

byte[] payload = "event=sensor-update status=ok\n".repeat(512)
        .getBytes(StandardCharsets.UTF_8);
try (OpenZLCompressor compressor = new OpenZLCompressor()) {
    compressor.setCompressionLevel(OpenZLCompressionLevel.LEVEL_3);
    compressor.configureProfile(OpenZLProfile.LZ);
    byte[] frame = compressor.compress(payload);
    if (!Arrays.equals(payload, compressor.decompress(frame))) {
        throw new IllegalStateException("LZ round trip failed");
    }
}

Training

Train representative samples once and reuse the resulting candidates:

  • trainCandidates(profile, byte[][] inputs, options) accepts sample arrays.
  • trainCandidatesFromDirectory(profile, directory, options) accepts an existing sample directory.

Both return TrainedCompressor[]. Load a chosen candidate with configureTrained(candidate). Each candidate owns defensive copies of its profile name, serialized graph and optional dictionary bundle. Check that the returned array is nonempty before selecting a candidate.

TrainOptions fieldMeaning
maxTimeSecsACE search budget for the whole search; default 1 second. Preprocessing, measurements and dictionary optimization can take additional time.
threadsTraining worker count; default 1.
numSamplesRequested sample count; 0 leaves the native default.
paretoFrontierRequest candidates offering different speed/size tradeoffs.
maxNumCandidatesLimit returned candidates in upstream order; 0 leaves the native default. Limits of 1–5 are supported.
formatVersionTarget format; 0 uses the native default, 24 targets OpenZL 0.2.0 readers.
dictionaryTrainingEnable dictionary training with a supporting profile such as zstd; default false.

The older train and trainFromDirectory methods still return self-contained graphs as byte[][]. They reject dictionary training because that return type cannot carry the bundle. configureProfile selects a preset; it does not reload a trained graph.

Train, save and reload dictionary bundles

Use samples representative of the data you will compress. Persist the profile name, graph and bundle together. A separate reader needs the matching bundle to decode dictionary-backed frames.

import io.github.hybledav.*;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.Arrays;

byte[][] samples = new byte[128][];
for (int i = 0; i < samples.length; i++) {
    samples[i] = ("order=" + i + " customer=account-" + i
            + " region=eu-central currency=EUR status=accepted "
            + "product=openzl-sample quantity=3 price=19.99 "
            + "Reusable dictionary compression sample for purchase orders. ".repeat(3))
            .getBytes(StandardCharsets.UTF_8);
}
TrainOptions options = new TrainOptions();
options.dictionaryTraining = true;
options.maxNumCandidates = 1;
options.maxTimeSecs = 2;
TrainedCompressor[] candidates =
        OpenZLCompressor.trainCandidates("zstd", samples, options);
if (candidates.length == 0) throw new IllegalStateException("No trained candidates");
TrainedCompressor candidate = candidates[0];

// Save the profile name, graph AND bundle together.
Path model = Files.createDirectories(Path.of("model"));
Files.writeString(model.resolve("profile.txt"), candidate.profileName());
Files.write(model.resolve("graph.bin"), candidate.serializedCompressor());
Files.write(model.resolve("dictionary.bin"), candidate.dictionaryBundle());

// Reload later, or in a different process.
TrainedCompressor loaded = new TrainedCompressor(
        Files.readString(model.resolve("profile.txt")),
        Files.readAllBytes(model.resolve("graph.bin")),
        Files.readAllBytes(model.resolve("dictionary.bin")));
try (OpenZLCompressor writer = new OpenZLCompressor();
     OpenZLCompressor reader = new OpenZLCompressor()) {
    writer.configureTrained(loaded);
    reader.setDictionaryBundle(loaded.dictionaryBundle());
    byte[] frame = writer.compress(samples[0]);
    if (!Arrays.equals(samples[0], reader.decompress(frame))) {
        throw new IllegalStateException("Dictionary round trip failed");
    }
}

TrainedCompressor is immutable and can be shared across independent compressor instances. reset() retains a loaded graph and bundle; close() releases their state. setDictionaryBundle(new byte[0]) clears the decoding bundle.

Dictionary-backed frames require format 25 or newer. Use self-contained training with dictionaryTraining = false for format 24. Published 0.3.0-1 requires self-contained Protobuf training; the unreleased work adds Protobuf dictionary candidates and conversion.

Brute-force selection and saved graphs

configureBruteForce tries the supplied graphs for each input and selects the smallest encoding. This spends extra compression work to improve size. Save its binary configuration with serializeCompressor() and reload it using configureTrained.

import io.github.hybledav.*;
import java.nio.charset.StandardCharsets;
import java.util.Arrays;

byte[] payload = "try several graphs for this block\n".repeat(256)
        .getBytes(StandardCharsets.UTF_8);
byte[] graph;
byte[] frame;
try (OpenZLCompressor writer = new OpenZLCompressor()) {
    writer.configureBruteForce(
            OpenZLGraph.ZSTD, OpenZLGraph.HUFFMAN, OpenZLGraph.STORE);
    graph = writer.serializeCompressor();
    frame = writer.compress(payload);
}
try (OpenZLCompressor restored = new OpenZLCompressor()) {
    restored.configureTrained(new TrainedCompressor("serial", graph, new byte[0]));
    if (!Arrays.equals(payload, restored.decompress(frame))) {
        throw new IllegalStateException("Restored graph round trip failed");
    }
}

This example uses the serial profile to restore a byte graph without a dictionary. For a trained dictionary candidate, preserve its original profile name and bundle instead.

Upgrading from OpenZL 0.2.0

Install matching base and platform artifacts, for example 0.3.0-1 for both. OpenZL 0.3.0 reads frames from 0.2.0. Its new default format 27 requires a newer reader.

import io.github.hybledav.*;
import java.nio.charset.StandardCharsets;

byte[] payload = "data for an OpenZL 0.2.0 reader"
        .getBytes(StandardCharsets.UTF_8);
try (OpenZLCompressor writer = new OpenZLCompressor()) {
    writer.setFormatVersion(24);
    byte[] legacyFrame = writer.compress(payload);
    if (writer.inspect(legacyFrame).formatVersion() != 24) {
        throw new IllegalStateException("Expected format 24");
    }
    writer.setFormatVersion(0); // Restore the native default: 27.
}
  • Compressed frames: select format 24 when writing for a 0.2.0 reader, using a graph that supports it. Features such as dictionary bundles require a newer format.
  • Saved compressor graphs: these have separate compatibility rules. Numeric graphs serialized by 0.3.0 require 0.3.0 even if their frames target format 24.
  • Training: set TrainOptions.formatVersion = 24 before training for older readers. Legacy Protobuf output requires explicitly trained format-24 graphs passed to the conversion overload accepting a trained compressor. Automatic Protobuf conversion defaults to format 27.
  • API scope: custom materializer registration and zero-copy multi-input compression remain outside this Java API. The upcoming wrapper revision adds typed multi-input snapshots, native diagnostics, typed options, LZ controls, the optional codec-output cache and Protobuf dictionary support.
